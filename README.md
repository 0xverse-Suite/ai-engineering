# AI Engineering

Public course workspace for machine-learning exercises, notebooks, AI applications, evaluation, automation, and portfolio projects.

**Course Lead:** To be assigned  
**Tutor team:** `@0xverse-Suite/ai-tutors`  
**Student course team:** `@0xverse-Suite/ai`

## Structure

- `assignments/` — briefs and evaluation criteria
- `notebooks/` — reproducible exploration
- `examples/` — tutor-maintained demonstrations
- `projects/` — reviewed AI applications
- `docs/` — model cards, setup, and responsible-use notes

Students use assigned Issues, feature branches, reproducible commits, pull requests, tutor review, revision, and approval. Do not commit model credentials, restricted data, personal data, or large model weights. See [STUDENT_GITHUB_GUIDE.md](STUDENT_GITHUB_GUIDE.md).

Escalate data licensing, privacy, safety, or publication questions to the tutor team.
