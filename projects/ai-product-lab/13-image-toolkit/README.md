# AIPL-13 — Image Toolkit

## Product

Provide fast background removal, 2×/4× enhancement, format conversion, compression, and transparent product-image export through one simple workflow.

- Primary track: AI Engineering
- Supporting tracks: Graphics Design, Frontend, UI/UX
- Target users: designers, ecommerce sellers, creators, and small businesses
- Status: Discovery

## MVP workflow

Upload image → validate/license confirmation → select operation → model processing → before/after review → edge/manual correction → export.

## Technical shape

Use replaceable segmentation/upscaling models, tiled inference for memory control, color/profile preservation, non-destructive originals, job queues, and preview caching.

## Delivery phases

1. Background removal with transparent PNG and correction mask.
2. Upscaling, compression, format presets, and batch jobs.
3. Quality routing, branded workflows, and measured fair-use limits.

## Success and safety

Measure edge quality, artifact rate, user correction, processing time, and cost per megapixel. Require image rights, preserve originals, avoid deceptive “restoration” claims, and prohibit abusive or illegal content.

## Portfolio evidence

Image-quality benchmark, before/after gallery using licensed assets, correction UI, inference performance report, and model/license register.
