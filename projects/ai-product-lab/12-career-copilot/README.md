# AIPL-12 — Career Copilot

## Product

Use a candidate's verified experience and a job description to produce an evidence-based CV draft, gap analysis, interview-preparation plan, and application checklist.

- Primary track: AI Engineering
- Supporting tracks: Frontend, UI/UX, Data Analytics
- Target users: students, career changers, and job seekers
- Status: Discovery

## MVP workflow

Import CV/profile → parse verified evidence → import role description → map requirements → suggest truthful revisions → candidate approval → DOCX/PDF export.

## Technical shape

Maintain a structured evidence store, prohibit unsupported achievements, highlight every generated change, use deterministic formatting, and let users delete all personal data.

## Delivery phases

1. CV parser, job comparison, and evidence-linked suggestions.
2. Editable resume export and interview question preparation.
3. Application tracker and outcome analytics with explicit consent.

## Success and safety

Measure factual consistency, accepted edits, parsing accuracy, accessibility, and user-reported usefulness—not hiring outcomes. Never fabricate experience, infer protected traits, rank people for employers, or retain personal data unnecessarily.

## Portfolio evidence

Evidence model, hallucination tests, accessible editor, redacted examples, privacy design, and fairness/limitations review.
