# Track Ownership

## Primary ownership

AI Engineering owns model selection, inference pipelines, prompting, retrieval, evaluation, guardrails, observability, and cost/latency measurement.

## Supporting ownership

- Backend: APIs, job queues, storage boundaries, authentication, billing hooks, integrations, and deployment.
- Frontend: upload/configuration flows, results workspace, accessibility, and client-side state.
- Fullstack: end-to-end vertical slices and integration quality.
- Mobile: capture, upload, notifications, offline-aware workflows, and mobile delivery.
- UI/UX: user research, workflow design, prototypes, usability testing, and design systems.
- Graphics Design: brand systems, visual templates, preview/export quality, and licensed assets.
- Data Analytics: datasets, data quality, metrics, experiment analysis, dashboards, and reporting.

Each Issue must identify one accountable track and any reviewing tracks. Cross-track work belongs in one project directory; it should not be duplicated across course repositories.
